Color pattern

Rate is color changes per loop for Random, and full palette cycles per loop for the others. Ramp length only applies to the Ramp transition. Jitter offsets each tile in time. Flash brightens a tile as it changes.

Print

Tile size is a target: it is nudged so whole tiles fill the space, and any spare goes into the border. Border and gaps are paper color (no ink). Print at 100% / actual size, not "fit to page".
